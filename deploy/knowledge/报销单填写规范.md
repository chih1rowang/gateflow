# 社团报销单填写规范

## 填写要求

1. 报销单必须用黑色签字笔或线上表单填写，涂改处需经办人签名确认，单张涂改超过 **2 处**的作废重填。
2. 金额一律大小写并列（如：￥320.00 / 叁佰贰拾元整），大小写不一致的以大写为准并退回修正。
3. "事项"栏须写明日期、用途、人数三要素，例如"9月5日摄影社外拍包车（10人）"；只写"交通费"三个字的直接退回。
4. 每张发票对应一行明细，多张发票不得合并为一行；发票与明细的粘贴顺序须与清单一致。
5. 经办人、部门负责人、财务复核三栏不得为同一人（自己不能审自己的单）。

## 常见退回原因统计

上学期退回率最高的三类问题：事项描述缺人数（占 41%）、发票抬头错误（占 27%）、大小写不符（占 18%）。

## 加急通道

考试周前后（第 16-18 教学周）可申请加急审核，48 小时内完成三审，但每学期每社团限用 3 次。
